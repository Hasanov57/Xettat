Necə işləyir

  1. Siz adi qaydada yazırsınız

    Hərfləri axtarmağa ehtiyac yoxdur: e, i, o, u, c, s, g ilə yazın.

  2. Model hər hərfə qərar verir

    Hər namizəd hərf üçün soruşur: olduğu kimi qalsın, yoxsa ə, ı, ö, ü, ç, ş, ğ olsun? Cavabı ətrafdakı sözlərə görə verir.

  3. Yalnız o hərflər dəyişir

    Rəqəmlərə, linklərə, ingiliscə sözlərə və artıq düzgün yazdığınız hərflərə toxunulmur. Mətnin uzunluğu eyni qalır.

Model Azərbaycan Vikipediyasının milyonlarla cümləsi üzərində öyrədilib. Hərflər avtomatik silinib, model onları geri qaytarmağı öyrənib. Extension-da model brauzerin içində işləyir, mətniniz heç yerə göndərilmir.

Chrome-a quraşdırın

  1. GitHub-dan repo-nu yükləyin və extension qovluğunu hazırlayın (təlimat extension/README.md-dədir).
  2. Chrome-da chrome://extensions açın, Developer mode-u yandırın.
  3. Load unpacked basıb extension qovluğunu seçin.
  4. İstənilən saytda mətn sahəsində Alt + Shift + X basın.
